# Refinamiento de interfaz

## Objetivo

Mejorar la experiencia visual y de uso de duoOffice respecto a la base de GenOffice, con especial atención a barras de menús, botoneras y los modos claro y oscuro.

## Alcance inicial

- Simplificar y ordenar las barras de menús para priorizar acciones frecuentes y mantener accesibles las avanzadas.
- Unificar el estilo, tamaño, estados y espaciado de botones, grupos de herramientas e iconos.
- Revisar la jerarquía visual, foco, estados deshabilitados, tooltips y accesibilidad por teclado.
- Refinar los tokens de color de los modos claro, oscuro y de sistema: contraste, fondos, bordes, superficies y estados interactivos.
- Mantener las superficies de documento con la fidelidad de visualización necesaria para los formatos Office, incluso cuando el chrome de la aplicación use tema oscuro.

## Criterios de aceptación

- Las acciones equivalentes presentan el mismo tratamiento visual en los distintos editores.
- Los controles mantienen contraste suficiente, foco visible y estado discernible en ambos temas.
- El cambio de tema no altera la legibilidad ni la fidelidad de documentos, hojas, presentaciones o PDF.
- Las decisiones se validan mediante revisión visual en macOS, Windows y Linux.

## Estado

Pendiente de auditoría visual y de una especificación detallada por área de interfaz.
